Tripideias

Visão geral

Tripideias é uma agência de viagens que vende pacotes turísticos personalizados, tudo para oferecer uma experiência única aos seus clientes.

Categoria
Atuação

Introdução do projeto

Este case documenta o processo de melhoria na experiência dos usuários que precisam realizar viagens corporativas, o que chamaremos nesse contexto de User business. Eu atuei como UX/UI Designer percorrendo o projeto desde a imersão, pesquisa, definição e entrega.

Cenário atual

Na empresa Tripideias o cliente direto é o gestor responsável por solicitar a viagem personalizada e nosso usuário final são seus liderados que utilizam dos serviços de pacotes de viagens.

Problemas encontrados

Orçamento demorado prejudicando as vendas.

Demora no atendimento uma vez que cada usuário tem um pacote personalizado

Clientes precisam fazer vários pedidos e de forma individual para os usuários (liderados)

Desafio

Melhorar a visão do itinerário e roteiro de cada viagem personalizada solicitada pelos clientes, diminuindo as interações com o pessoal de atendimento e aumentando a adesão aos pacotes.

Processo de Design

Seguindo a dinâmica de atuação do Double Diamond, separamos o projeto em 3 grandes entregas

Contexto do problema

Etapa que realizamos as pesquisas e análise de dados de mercado. Conhecendo o perfil de uso, dores do cliente, dores do usuário e gerando as personas

Proposta de valor

Visão estratégica de como usamos o UX para resolver as dores dos usuários e ser rentável para empresa, como entregável dessa etapa, fizemos o canvas de proposta de valor e o ux canvas sempre buscando equilíbrio entre usuário e negócio

Contexto da solução

Momento em que realizamos o desenvolvimento da proposta de resolução do produto.

Conhecendo o usuário

Para esse projeto era importante compreender se o que foi dito como problema para o usuário, era realmente um problema ou era apenas um sintoma.

A partir de uma pesquisa quantitativa, foram criadas personas para cada tipo de perfil de usuário.
