Tripideias

Overview

Tripideias is a travel agency that sells personalized travel packages, all to offer a unique experience to its customers.

Category
Role

Project introduction

This case documents the process of improving the experience of users who need to make corporate trips, which we will call User business in this context. I worked as a UX/UI Designer going through the project from immersion, research, definition, and delivery.

Current scenario

At Tripideias, the direct client is the manager responsible for requesting the personalized trip, and our end users are their team members who use the travel package services.

Problems found

Delayed budgeting hurting sales.

Slow service since each user has a personalized package.

Clients need to make multiple requests individually for users (team members).

Challenge

Improve the view of the itinerary and schedule of each personalized trip requested by clients, reducing interactions with service personnel and increasing package adoption.

Design Process

Following the Double Diamond approach, we divided the project into 3 major deliveries

Problem context

Stage where we conducted research and market data analysis. Understanding the usage profile, client pain points, user pain points, and generating personas.

Value proposition

Strategic vision of how we use UX to solve user pain points and be profitable for the company. As deliverables for this stage, we created the value proposition canvas and the UX canvas, always seeking balance between user and business.

Solution context

Moment when we developed the product resolution proposal.

Getting to know the user

For this project, it was important to understand if what was stated as a problem for the user was really a problem or just a symptom.
